# Frontend

React 19 + TypeScript + Inertia v3, Tailwind v4, shadcn/ui (Radix), Wayfinder for typed routes. Built by Vite; ESLint, Prettier and `tsc` are part of `npm run check`.

## Two shells, one app
| Shell | Entry | Blade root | Layout | CSS |
|---|---|---|---|---|
| Back office (`/admin/*`) | `resources/js/app.tsx` | `resources/views/admin.blade.php` | `layouts/app-layout.tsx` (sidebar, header with bell and theme, sticky footer slot) | `resources/css/app.css` |
| Storefront (everything else, incl. auth) | `resources/js/storefront.tsx` | `resources/views/app.blade.php` | `layouts/storefront-layout.tsx` (nav, cart drawer, chat, Lenis) | `resources/css/storefront.css` |

`HandleInertiaRequests::rootView()` picks the shell by URL. Pages live in `resources/js/pages/<module>/<page>.tsx`; the Inertia component name is the path.

## Folders
| Folder | What's in it |
|---|---|
| `components/ui/` | shadcn primitives (32). Restyled through tokens only; no ad-hoc colours. |
| `components/custom/` | Back-office building blocks: data table, filters, stat cards, form sections, field, select dropdown, page actions, confirm dialog, notification bell, menu icon map. |
| `components/storefront/` | Storefront pieces: nav, footer, cart drawer and lines, product card and quick view, purchase panel, reviews, chat widget, PSGC address fields, Leaflet map picker, 3D showcase. |
| `schemas/<module>/` | Per-module table columns, filters and stat-card config for the generic data-table pages. |
| `renderers/cells/` | Table cell renderers (money, badges, dates…). |
| `hooks/` | `use-cart`, `use-permissions`, `use-data-table-page`, `use-flash-toast`, `use-appearance`, … |
| `lib/` | `http.ts` (JSON + XSRF for the few non-page endpoints), `format.ts` (peso, numbers), the three.js scene (plain JS, lazy-loaded). |
| `types/` | Shared TS types. IDs are **strings** (UUIDs) everywhere. |
| `routes/`, `actions/`, `wayfinder/` | Generated by Wayfinder (`php artisan wayfinder:generate --with-form`); never edit by hand. |

## Conventions
- Data goes through Inertia props; the few JSON endpoints (chat, quotes, bell) use `lib/http.ts`.
- Flash toasts: `Inertia::flash('toast', …)` on the server, shown by `use-flash-toast`.
- Permissions on the client (`use-permissions`) only hide UI; the server enforces them.
- Menu icons are a static map (`menu-icon.tsx`) to keep the bundle small.
